## How to Run the Code

### 1. Running GUI & Basic Java Programs (Experiments 1–5)
1. Clone the repository:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git](https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git)

1.  Navigate to the desired folder (e.g., Experiment-1 or Experiment-5).

Compile and run the Java files:

Bash
javac Main.java
java Main

2. Running Servlet / JSP Web Projects (Experiments 6–8)

Download and set up Apache Tomcat 11.0.25.

Deploy the web project .war file or directory to the Tomcat webapps folder.

Start the server using bin/startup.bat (Windows) or bin/startup.sh (Linux/Mac).

Access the web application in your browser at http://localhost:8080/.

3. Running the Main Project (ShopSphere)

# Navigate to the project directory:

Bash
cd ShopSphere_Project

# If using an IDE (VS Code / Eclipse / IntelliJ):

Open the ShopSphere_Project folder.

Run the main entry file (Main.java or App.java).

# If running via Command Line:

Bash
javac Main.java
java Main
